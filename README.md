# TF2 Minecraft Mashup

A Minecraft: Java Edition mod that lets you play as all 9 Team Fortress 2 mercs in a co-op survival world.

## Current build focus

- Fabric mod scaffold in place
- Data-driven merc system planned
- Local test run next

## Design

- Host game: Minecraft Java Edition
- Primary gameplay: Minecraft survival/building/exploration
- TF2 layer: all 9 mercs, class identities, and weapon behavior in Minecraft
- Multiplayer: small co-op in the same world
- License: credit-only remixing
